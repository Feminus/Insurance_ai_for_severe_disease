## 重点重疾(高发 + 边界多)

### R001 恶性肿瘤——重度 ⭐

**最常见 + 最易边界出错**。**大伞规则**,涵盖 C00-C97 全部恶性 ICD。

|维度|详情|
|-|-|
|ICD 范围|C00-C97(整段恶性肿瘤)|
|核心 criteria|(1) 病理确诊;(2) ICD-10 属 C00-C97;(3) ICD-O-3 形态学 3/6/9|
|关键 exclusions|(1) ICD-O-3 形态学 0/1/2(良性/动态未定性/原位癌);(2) TNM Ⅰ 期甲状腺癌;(3) T1N0M0 前列腺癌;(4) 非黑素瘤未转移皮肤癌;(5) CLL Binet A 期;(6) 霍奇金 Ann Arbor Ⅰ 期;(7) 神经内分泌瘤 G1|
|子类示例|肺腺癌(C34)、胃腺癌(C16)、肝细胞癌(C22)、急性髓系白血病(C92)、多发性骨髓瘤(C90)|
|**典型边界**|病理报告 / 影像报告里"考虑 / 怀疑 / 不排除"恶性 → 严格按 exclusions + LLM 自评|

**常见边界冲突**:

* 听神经瘤(良性,D33.3)— **不**是 R001(应走 R009 严重非良性颅内肿瘤,但该规则很严)
* 甲状腺癌 TNM Ⅰ 期 → 排除
* 原位癌(ICD-O-3 形态学 2)→ 排除

### R002 较重急性心肌梗死

|维度|详情|
|-|-|
|核心 criteria|(1) CK-MB / cTn 升高达到诊断标准 + 证据(胸痛/心电图/Q波/影像);(2) **任一**严重度:cTn ≥ 15× / CK-MB ≥ 2× / 6周后 LVEF < 50% / 乳头肌断裂二尖瓣反流 / 室壁瘤 / 室速/室颤/心源性休克|
|关键指标|**cTn, CK-MB, LVEF**(必抽)|
|**典型边界**|缺 cTn → "无法认定 - 缺指标"|

### R003 严重脑中风后遗症

|维度|详情|
|-|-|
|核心 criteria|影像证实 + **180 天后**仍遗留下列之一:肌力 2 级以下 / 语言能力完全丧失 / 自主生活能力完全丧失|
|关键时间|**确诊 180 天**|
|**典型边界**|急性期脑梗死,无 180 天功能障碍证据 → 判否|

### R005 冠状动脉搭桥术

|维度|详情|
|-|-|
|核心 criteria|治疗严重冠心病 + **切开心包**的旁路移植|
|**典型边界**|介入治疗(支架)— **不**算;R002 心肌梗死后做搭桥算|

### R006 严重慢性肾衰竭

|维度|详情|
|-|-|
|核心 criteria|双肾慢性不可逆衰竭 + K/DOQI 分期 **5 期** + 规律透析 **≥ 90 天**|
|关键指标|透析天数、肌酐清除率、eGFR|

### R009 严重非恶性颅内肿瘤 ⚠️

**容易误伤**。本案例中"听神经瘤"被命中,业务标注"否"。

|维度|详情|
|-|-|
|ICD 范围|D32 / D33 / D35.2(良性)|
|核心 criteria|(1) ICD-O-3 形态学 0/1(良性/动态未定性);(2) 已引起颅内压升高或神经损害;(3) 影像证实;(4) **任一**:开颅切除 / 放射治疗|
|exclusions|脑垂体瘤 / 脑囊肿 / 颅内血管性疾病(动脉瘤/动静脉畸形等)|
|**典型边界**|听神经瘤、神经鞘瘤、脑膜瘤 — 临床认为不一定"严重"时,业务可能标否|

### R013 双耳失聪 / R014 双目失明

|维度|详情|
|-|-|
|关键年龄|**≥ 3 周岁**|
|R013 标准|平均听阈 ≥ 91dB(500/1000/2000Hz)|
|R014 标准|矫正视力 < 0.02 或视野 < 5°|

### R020 严重Ⅲ度烧伤

|维度|详情|
|-|-|
|核心 criteria|Ⅲ度 + **面积 ≥ 20%** 体表面积|
|计算法|《中国新九分法》|
|R082 关联|意外导致重度面部烧伤 — 面部 2/3 或体表 2%|

### R024 重型再生障碍性贫血

|维度|详情|
|-|-|
|核心 criteria|(1) 骨髓增生 < 25%(或 < 50% 但残存造血 < 30%);(2) **外周血三系任两项异常**:ANC < 0.5×10⁹/L / 网织红 < 20×10⁹/L / PLT < 20×10⁹/L|

### R031 严重多发性硬化症

|维度|详情|
|-|-|
|核心 criteria|中枢神经脱髓鞘 + **180 天**持续无法独立完成"移动"或"进食"|

### R050 严重急性主动脉夹层血肿

|维度|详情|
|-|-|
|核心 criteria|主动脉夹层 + 影像证实 + \*\*急性期(发病 2 周内)\*\*传统或微创开胸/开腹手术|
|exclusions|慢性期择期手术 / 经导管介入|

### R075 因疾病或外伤导致智力缺陷

|维度|详情|
|-|-|
|关键|**≥ 6 周岁**|
|IQ 标准|轻度 50-70 / 中度 35-49 / 重度 20-34 / 极重度 < 20|
|关键|IQ 70-85 临界**不在**保障范围|

## 边界判定速查

|场景|规则|结论|
|-|-|-|
|病理报告说"腺癌"但无 TNM|R001|走 R001,LLM 自评 confidence|
|病理报告说"原位癌"|R001|exclusions 命中 → 否|
|病理报告说"良性肿瘤"|R001|形态学 0/1 → 否|
|急性心梗但只查了 ECG,无 cTn|R002|缺指标 → 无法认定|
|急性心梗 cTn 正常|R002|criteria 未过 → 否|
|脑中风但只 30 天|R003|criteria 未过(需 180 天)→ 否|
|脑中风 180 天后,肌力 3 级|R003|需肌力 ≤ 2 级 → 否|
|双侧肾衰但未规律透析|R006|缺指标 → 无法认定|
|听力下降 80dB|R013|标准 ≥ 91dB → 否|
|烧伤 15%|R020|标准 ≥ 20% → 否|
|甲状腺乳头状癌(无 TNM)|R001|LLM 自评,可能匹配 R001|
|听神经瘤|R009|易误判,实际看病情严重度|

## 调优路线图

1. **跑全量案例** — 拿全量准确率
2. **按 R 规则分组** 看错例集中在哪几条
3. **R009 单独优化** — 加"必须开颅切除或放疗"以外的其他严重度判据
4. **R002 / R006 / R024 等"硬指标"规则** — 缺指标判定可能过严,考虑在抽取阶段多轮追问
5. **合成 100 种规则的测试集** — 解决训练集只覆盖 5% 规则的问题
6. **置信度阈值重新校准** — 80% 阈值是拍脑袋,用全量打标数据调
